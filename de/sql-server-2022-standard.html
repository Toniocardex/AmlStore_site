FAQ

Antworten vor dem Kauf

Brauche ich CALs für SQL Server?

Nein. Die Kernlizenzierung erfordert keine Clientzugriffslizenzen: beliebig viele Benutzer oder Anwendungen können die Datenbank nutzen, ohne Kosten pro Arbeitsplatz.

Gibt es eine Mindestanzahl zu lizenzierender Kerne?

Ja: Microsoft verlangt mindestens vier lizenzierte Kerne für jeden physischen Server oder jede virtuelle Maschine mit SQL Server.

Auf welchen Betriebssystemen kann ich installieren?

Windows Server 2016 und neuer, einschließlich Server-Core-Installationen, oder Windows 10 Version 1607 und neuer. Erfordert .NET Framework 4.7.2.

In welcher Sprache ist das Betriebssystem?

Das OEM-Medium ist englisch: Oberfläche und Installation sind auf Englisch. Prüfe das vor der Bestellung, falls du eine andere Sprache brauchst.
