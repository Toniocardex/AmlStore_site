Domande Frequenti

Hai dubbi prima dell'acquisto?

Servono CAL per SQL Server?

No. Con la licenza per core non sono richieste licenze di accesso client: possono usare il database quanti utenti o applicazioni vuoi, senza costi per postazione.

C'è un minimo di core da licenziare?

Sì: Microsoft richiede almeno quattro core licenziati per ogni server fisico o macchina virtuale su cui installi SQL Server.

Su quali sistemi operativi si installa?

Su Windows Server 2016 e versioni successive, comprese le installazioni Server Core, oppure su Windows 10 versione 1607 e successive. Richiede .NET Framework 4.7.2.

In che lingua è il sistema operativo?

Il supporto OEM è in lingua inglese: interfaccia e installazione sono in inglese. Verificalo prima dell'acquisto se ti serve l'italiano.
