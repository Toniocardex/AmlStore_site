FAQ

Le risposte prima dell'acquisto

Le CAL sono incluse nel prezzo?

No. Windows Server richiede una licenza di accesso client (CAL) per ogni utente o dispositivo che usa il server, e non è compresa in questa licenza. Le CAL si acquistano separatamente e valgono per l'intero ambiente, non per singolo server.

Cosa succede se il mio server ha più di 16 core?

La licenza copre 16 core. Se il server ne ha di più devi licenziare tutti i core fisici, acquistando licenze aggiuntive. Microsoft richiede un minimo di 16 core licenziati per server.

Quante macchine virtuali posso eseguire?

L'edizione Standard dà diritto a due ambienti di sistema operativo (o container Windows con isolamento Hyper-V) quando tutti i core fisici del server sono licenziati. Servono licenze aggiuntive oltre questo limite.

In che lingua è il sistema operativo?

Il supporto OEM è in lingua inglese: interfaccia e installazione sono in inglese. Verificalo prima dell'acquisto se ti serve l'italiano.

Requisiti di sistema

Compatibilità e requisiti tecnici

Valori indicativi dalla documentazione Microsoft. Verifica sempre i requisiti aggiornati prima dell'installazione.

Processore

Processore 64 bit da almeno 1,4 GHz. La versione 2025 richiede in più le istruzioni SSE4.2 e POPCNT: verifica la CPU prima di acquistare.

Memoria

2 GB per Server Core e 2 GB con Desktop Experience, 4 GB consigliati.

Spazio su disco

Almeno 32 GB liberi sulla partizione di sistema. Server con oltre 16 GB di RAM richiedono spazio aggiuntivo per paging e file di dump.

Rete

Adattatore Ethernet con throughput di almeno 1 Gbit/s, conforme alle specifiche PCI Express.
