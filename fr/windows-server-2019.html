FAQ

Les réponses avant d'acheter

Les CAL sont-elles incluses dans le prix ?

Non. Windows Server exige une licence d'accès client pour chaque utilisateur ou appareil utilisant le serveur, et elle n'est pas comprise ici. Les CAL s'achètent séparément et couvrent tout votre environnement, pas un seul serveur.

Que se passe-t-il si mon serveur a plus de 16 cœurs ?

La licence couvre 16 cœurs. Si le serveur en compte davantage, tous les cœurs physiques doivent être licenciés : il faut donc des licences supplémentaires. Microsoft impose un minimum de 16 cœurs licenciés par serveur.

Combien de machines virtuelles puis-je exécuter ?

L'édition Standard donne droit à deux environnements de système d'exploitation (ou conteneurs Windows avec isolation Hyper-V) dès lors que tous les cœurs physiques du serveur sont licenciés. Au-delà, des licences supplémentaires sont nécessaires.

Dans quelle langue est le système d'exploitation ?

Le support OEM est en anglais : l'interface et l'installation sont en anglais. Vérifiez-le avant de commander si vous avez besoin d'une autre langue.
