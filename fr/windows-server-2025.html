Pourquoi le choisir

Ce que couvre cette licence

  • ✓

    Couvre 16 cœurs

    La licence couvre un serveur avec au maximum 16 cœurs physiques. Si le vôtre en compte davantage, des licences supplémentaires sont nécessaires.

  • ✓

    Les CAL ne sont pas incluses

    Windows Server exige une CAL par utilisateur ou appareil accédant au serveur. Elle n'est pas comprise dans cette licence et s'achète séparément.

  • ✓

    Jusqu'à 2 environnements serveur

    L'édition Standard donne droit à deux environnements de système d'exploitation, ou conteneurs Windows avec isolation Hyper-V, dès lors que tous les cœurs physiques sont licenciés.

  • ✓

    Active Directory, Hyper-V, fichiers et web

    Inclut les rôles de Windows Server Standard : services de domaine Active Directory, Hyper-V, serveur de fichiers et d'impression, IIS.

  • ✓

    Licence numérique par e-mail

    Clé et instructions arrivent par e-mail après confirmation du paiement : rien à attendre par la poste.

  • ✓

    Mises à jour sans redémarrage

    Windows Server 2025 apporte le hotpatching via Azure Arc, qui réduit les redémarrages planifiés, ainsi qu'un Active Directory renforcé et la prise en charge native NVMe.

FAQ

Les réponses avant d'acheter

Les CAL sont-elles incluses dans le prix ?

Non. Windows Server exige une licence d'accès client pour chaque utilisateur ou appareil utilisant le serveur, et elle n'est pas comprise ici. Les CAL s'achètent séparément et couvrent tout votre environnement, pas un seul serveur.

Que se passe-t-il si mon serveur a plus de 16 cœurs ?

La licence couvre 16 cœurs. Si le serveur en compte davantage, tous les cœurs physiques doivent être licenciés : il faut donc des licences supplémentaires. Microsoft impose un minimum de 16 cœurs licenciés par serveur.

Combien de machines virtuelles puis-je exécuter ?

L'édition Standard donne droit à deux environnements de système d'exploitation (ou conteneurs Windows avec isolation Hyper-V) dès lors que tous les cœurs physiques du serveur sont licenciés. Au-delà, des licences supplémentaires sont nécessaires.

Que reçois-je exactement ?

Vous recevez la clé de licence et les instructions par e-mail après confirmation du paiement. La livraison est uniquement numérique : aucun support physique n'est expédié.
