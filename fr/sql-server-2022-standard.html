FAQ

Les réponses avant d'acheter

Faut-il des CAL pour SQL Server ?

Non. La licence par cœur n'exige aucune licence d'accès client : autant d'utilisateurs ou d'applications que vous le souhaitez peuvent utiliser la base, sans coût par poste.

Y a-t-il un minimum de cœurs à licencier ?

Oui : Microsoft impose au moins quatre cœurs licenciés pour chaque serveur physique ou machine virtuelle exécutant SQL Server.

Sur quels systèmes d'exploitation puis-je l'installer ?

Windows Server 2016 et versions ultérieures, y compris les installations Server Core, ou Windows 10 version 1607 et ultérieure. Nécessite .NET Framework 4.7.2.

Dans quelle langue est le système d'exploitation ?

Le support OEM est en anglais : l'interface et l'installation sont en anglais. Vérifiez-le avant de commander si vous avez besoin d'une autre langue.
