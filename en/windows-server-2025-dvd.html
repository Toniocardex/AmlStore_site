FAQ

Answers before you buy

Are CALs included in the price?

No. Windows Server requires a Client Access Licence for every user or device using the server, and it is not part of this licence. CALs are bought separately and cover your whole environment rather than a single server.

What if my server has more than 16 cores?

The licence covers 16 cores. If your server has more, every physical core must be licensed, so you buy additional licences. Microsoft requires a minimum of 16 licensed cores per server.

How many virtual machines can I run?

Standard edition grants two operating system environments (or Windows containers with Hyper-V isolation) once every physical core in the server is licensed. Beyond that you need additional licences.

What language is the operating system in?

The OEM media is English: the interface and setup are in English. Check this before ordering if you need another language.
