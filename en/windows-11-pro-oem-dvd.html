How it works

Installation and activation

  1. Check compatibility

    Before buying, confirm the PC meets Windows 11 hardware requirements (CPU, RAM, TPM 2.0, UEFI with Secure Boot).

  2. Install Windows 11 Pro

    Insert the English DVD and start setup. Without a DVD drive, create a USB install media with official Microsoft tools, then use the Product Key on the COA.

  3. Activate Windows

    Then: Settings → System → Activation → Change product key. Enter the key on the COA and complete activation via Microsoft services.

FAQ

Answers before you buy

Is this delivered by email?

No. It is a physical product with DVD and COA, shipped to your address. You receive order confirmation and shipping/tracking emails.

How does it differ from ESD?

ESD is digital-only by email. This page includes a physical English DVD and COA with Product Key, shipped by courier.

Can I install it on multiple PCs?

No. You need a separate licence for each device where Windows is installed and used.

Can I install without a DVD drive?

Yes. Create USB install media with official Microsoft tools and activate with the Product Key on the COA.

Can I upgrade from Windows 11 Home?

It depends on the PC configuration. Check compatibility and that Windows 11 Pro is installed.

Is activation guaranteed?

The key must be used under licence terms on the correct edition. For install or activation issues, contact Aml Store support.
