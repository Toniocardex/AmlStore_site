Perguntas frequentes

Respostas antes de comprar

As CAL estão incluídas no preço?

Não. O Windows Server exige uma licença de acesso de cliente (CAL) para cada utilizador ou dispositivo que usa o servidor, e não está incluída nesta licença. As CAL compram-se em separado e valem para todo o ambiente, não para um único servidor.

O que acontece se o meu servidor tiver mais de 16 núcleos?

A licença cobre 16 núcleos. Se o servidor tiver mais, tens de licenciar todos os núcleos físicos, comprando licenças adicionais. A Microsoft exige um mínimo de 16 núcleos licenciados por servidor.

Quantas máquinas virtuais posso executar?

A edição Standard dá direito a dois ambientes de sistema operativo (ou contentores Windows com isolamento Hyper-V) quando todos os núcleos físicos do servidor estão licenciados. Além deste limite são necessárias licenças adicionais.

O que recebo exatamente?

Recebes o código de licença e as instruções por email após a confirmação do pagamento. A entrega é apenas digital: não é enviado nenhum suporte físico.
