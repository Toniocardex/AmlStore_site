Cómo funciona

Instalación y activación

  1. Comprobar compatibilidad

    Antes de comprar, confirma que el PC cumple los requisitos de Windows 11 (CPU, RAM, TPM 2.0, UEFI con Arranque seguro).

  2. Instalar Windows 11 Pro

    Inserta el DVD en inglés e inicia la instalación. Sin unidad DVD, crea un USB con las herramientas oficiales Microsoft y usa el Product Key del COA.

  3. Activar Windows

    Después: Configuración → Sistema → Activación → Cambiar clave de producto. Introduce la clave del COA y completa la activación con Microsoft.
